# Code of Conduct

## Our commitment

We want SnapKit to be a welcoming project for everyone, regardless of experience, background, identity or language. We commit to making participation a harassment-free experience for all.

## Expected behavior

- Be kind and patient, especially with newcomers.
- Assume good intent, and ask before you assume.
- Give and receive feedback about the work, not the person.
- Respect that people have different skills, time and priorities.
- Write in a way that people using translation tools can follow.

## Unacceptable behavior

- Harassment, insults, or discriminatory jokes and language.
- Personal or political attacks.
- Publishing someone else's private information without permission.
- Sexualized language or imagery.
- Any other conduct that would be inappropriate in a professional setting.

## Scope

This code applies to all project spaces, including issues, pull requests, discussions and any public space where someone represents the project.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer privately through the email address on the maintainer's [GitHub profile](https://github.com/MichelGSS), or open a [private security advisory](https://github.com/MichelGSS/snapkit/security/advisories/new) if no email is listed. Reports are handled confidentially.

## Enforcement

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that don't follow this code, and may temporarily or permanently ban anyone whose behavior is harmful to the community.

This code of conduct is adapted from the principles of the [Contributor Covenant](https://www.contributor-covenant.org).
