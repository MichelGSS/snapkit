# Tutorial: Create a step-by-step guide for your documentation

In this tutorial, you record a short task with **Step by step** capture and turn it into a single image with numbered steps and captions, ready to drop into a knowledge base article, a README or a support reply.

You'll document a simple task: creating a new folder in File Explorer. Once you know the workflow, you can use it for any task in any app.

**Time:** about 15 minutes
**You need:** SnapKit installed and File Explorer open on any folder where you can create a test folder, such as **Documents**.

## Step 1: Start a step-by-step capture

1. Open File Explorer on the folder you'll use.
2. Open SnapKit and select **Step by step** in the top bar.
3. Move the pointer over the File Explorer window and select it. You can also drag to select only part of the window; in that case, press **Enter** to confirm the area.

A small panel appears next to the area, and an orange frame shows what will be captured.

## Step 2: Record the task

1. In the panel, select **Start**.
2. Do the task at a normal pace:
   1. Right-click an empty spot in the folder.
   2. Select **New**, and then select **Folder**.
   3. Type `Test folder` and press **Enter**.

Each click inside the area and each **Enter** becomes a step. The panel counts them as you go.

> [!TIP]
> If you click something by mistake, select **Remove the last one** in the panel. SnapKit discards the last step and you can continue.

3. When you're done, select **Finish** in the panel.

## Step 3: Review the guide

SnapKit opens the result in the editor: one image with every shot stacked in order. Each shot has:

- A caption above it, such as **Step 1: right-click** or **Step 3: press Enter**.
- A numbered marker where you clicked.

Scroll through the image, or press **Ctrl+0** to see all of it at once.

## Step 4: Rewrite the captions

The default captions describe the action. Make them describe the goal:

1. In the tool column, select **Select**.
2. Double-click the first caption.
3. Replace the text, for example with `Step 1: Right-click an empty area of the folder`.
4. Press **Enter** to confirm.
5. Repeat for the other captions.

> [!NOTE]
> Captions and markers are regular annotations. You can move a marker by dragging it, change its color in the options bar, or delete it with **Delete**.

## Step 5: Highlight what matters

Optionally, make the important part of a step stand out:

1. In the tool column, select **Highlighter** and drag over a menu item.
2. Or select **Spotlight** and drag over the area that should stay bright. Everything else in the image darkens.

## Step 6: Hide anything private

If a shot shows a user name, a path with your name or other personal data, select **Blur** or **Pixelate** and drag over it.

## Step 7: Save the guide

1. In the top bar, select **Save PNG**.
2. Choose a folder, type a file name such as `create-folder.png`, and select **Save**.

The guide is also kept in the SnapKit library, so you can come back to it later.

## What you learned

- **Step by step** turns each click and **Enter** into a captioned, numbered shot.
- The captions and markers stay editable in the editor.
- You can combine the guide with any other annotation tool before you save it.
