# Copy, save and reuse captures

When a capture opens in the editor, SnapKit has already copied it to the clipboard and kept it in the library. In quick annotation, that happens when you copy, save or continue in the editor. Use these options to get the image where you need it.

## Copy to the clipboard

- In quick annotation, press **Enter** or **Ctrl+C**.
- In the editor, select **Copy** in the top bar. The copy includes every annotation.

Then press **Ctrl+V** in any app: Word, Google Docs, Confluence, Notion, Slack, Teams, Outlook, Jira, GitHub and so on.

## Save as a PNG file

- In quick annotation, press **Ctrl+S**.
- In the editor, select **Save PNG** in the top bar.

Choose a folder and a name, and select **Save**. SnapKit saves lossless PNG files, which keep text sharp.

> [!TIP]
> Name files after what they show, such as `settings-enable-sync.png`. It makes them easier to find in a documentation repository.

## Get the original file from the library

Every capture is already a PNG file in `Pictures\SnapKit`. In the library, right-click a capture and select **Show in folder** to drag the file into another app or upload it.

## Paste into Markdown documentation

1. Save the capture with **Save PNG** into your documentation's images folder.
2. Reference it in your Markdown file:

   ```markdown
   ![Settings page with the Sync option turned on](images/settings-enable-sync.png)
   ```

Write alternative text that describes what the image shows, for readers who use screen readers.
