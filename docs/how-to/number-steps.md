# Number the steps of a procedure

Numbered markers show the order of actions on a single screenshot, for example "1: open the menu, 2: select Settings, 3: turn on the option". To capture a whole task as a series of shots, use [Step by step capture](../tutorials/step-by-step-guide.md) instead.

## Add numbered markers

1. In the editor, select **Step** in the tool column. It's also in the quick annotation toolbar.
2. Select each place on the image, in order.

Each click places the next number: 1, 2, 3… A preview under the pointer shows the number that comes next.

## Change the look of the markers

In the options bar:

- Under **Shape**, choose **Circle**, **Square**, **Diamond**, **Hexagon** or **Pin**.
- In the next list, choose **1 2 3**, **A B C** or **a b c**.
- Drag **Size** to make the markers larger or smaller.
- Select a color. The number switches between white and black automatically to stay readable.

## Fix the numbering

- **Undo a marker:** press **Ctrl+Z**. The number is given back, so the next marker reuses it.
- **Delete a marker in the middle:** select it with **Select** and press **Delete**. The next marker continues after the largest number on the image.
- **Change a number:** select the marker with **Select** and change the value in **No.** in the options bar.
- **Move a marker:** drag it with **Select**.
