# Save your favorite tool settings as styles

If you use the same annotations again and again, such as a thick red dashed arrow for "click here" or a yellow callout for notes, save them as styles. A style remembers the tool and all its options, and applies them with one click.

## Save a style

1. Select a tool and set it up the way you like: color, width, **Dashed**, **Two heads**, shape and so on.
2. Select **Styles** in the options bar.
3. Under **Save the current tool and options**, type a name, for example `Click here arrow`. If you leave the name empty, SnapKit names the style after the tool.
4. Select **Save**.

If an annotation is selected when you save, the style uses that annotation's type and options.

## Use a style

1. Select **Styles** in the options bar.
2. Select the style's name.

SnapKit switches to the style's tool with its options. Draw as usual.

## Delete a style

1. Select **Styles**.
2. Select **×** next to the style.

Styles are saved in your preferences, so they're still there after you close SnapKit or update it.
