# Crop, resize, rotate and frame an image

These changes apply to the whole image. Do them before you annotate: annotations made before a crop, cut-out, rotation or resize become part of the image and can't be selected anymore.

## Crop

1. Select **Crop** in the **Image** group of the tool column.
2. Drag over the part of the image you want to keep.

Everything outside is removed. Press **Ctrl+Z** to undo.

## Remove a strip from the middle

**Cut out** removes a band from the image and joins the two remaining parts. Use it to shorten a long list or skip an empty area.

1. Select **Cut out**.
2. Drag **down** to remove a horizontal strip (rows), or drag **sideways** to remove a vertical strip (columns).

A preview shows the strip that will be removed.

## Rotate or flip

1. Select **Image** in the options bar.
2. Select **Rotate left**, **Rotate right**, **Flip horizontally** or **Flip vertically**.

## Resize

1. Select **Image** in the options bar.
2. Under **Size**, enter the new width or height in pixels. Keep **Keep proportions** selected to change both together.
3. Select **Apply size**.

## Add a border or a shadow

1. Pick a color in the options bar. The border uses the current color.
2. Select **Image** in the options bar.
3. Under **Frame**, select one of these:
   - **Border in the current color**, with the width set in the **Image** menu.
   - **Shadow**, which adds a white margin and a soft drop shadow. Use it to make screenshots stand out when you paste them into documents or slides.
