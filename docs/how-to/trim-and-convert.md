# Trim a recording and convert it to GIF

When a video recording stops, SnapKit opens the **Recording saved** window. Use it to keep only the useful part and to make a GIF, without another app. The original video is never changed.

## Open or locate the video

- Select **Open** to play the video in your default player.
- Select **Show in folder** to open `Videos\SnapKit` with the file selected.

## Save only part of the video

1. Under **Clip**, set **Start** and **End**, in seconds.
2. Select **Save only this clip**.

SnapKit saves the clip as a new MP4 next to the original. The cut is accurate to the frame.

## Convert to GIF

1. Under **Clip**, set **Start** and **End** for the part you want. Leave the full length to convert the whole video.
2. Choose **Frames per second**: **8**, **12**, **15** or **24**.
3. Choose **Width**: **320 px**, **480 px**, **720 px**, **960 px** or **Original**.
4. Select **Create GIF**.

The GIF is saved next to the video. More frames per second and a larger width give a smoother GIF but a bigger file. For documentation, 12 frames per second at 720 px is a good starting point.

SnapKit builds a color palette for each GIF, so colors stay clean, without the usual dithering.
