# SnapKit user guide

SnapKit is a free, open-source screen capture tool for Windows. It captures, annotates, reads text from images and records video, and it runs **100% on your computer**: no account, no cloud, no telemetry.

It's built for people who work with documentation: technical writers, support teams, QA engineers, trainers and developers who need clear screenshots, step-by-step guides and short demos every day.

This guide follows the [Diátaxis](https://diataxis.fr) framework. Pick the section that matches what you need right now.
