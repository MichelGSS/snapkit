# Keyboard shortcuts

## Global

These work from any app while SnapKit is running, including when it's hidden in the tray.

| Shortcut | Action |
|---|---|
| **Alt+Shift+S** | Start a region capture. You can change it in [Preferences](preferences.md#global-capture-shortcut). |
| Custom per-mode shortcuts | Optional global shortcuts for **Full screen**, **All screens**, **Scrolling**, **Panoramic**, **Step by step** and **Video**, configured in [Preferences](preferences.md#global-capture-shortcut). |

## Selecting an area

| Shortcut | Action |
|---|---|
| Drag | Select a region |
| Click | Capture the window under the pointer |
| **Enter** or **Ctrl+C** | Confirm an adjusted region |
| Double-click inside the region | Confirm an adjusted region |
| **Esc** | Cancel the capture |

## Quick annotation

| Shortcut | Action |
|---|---|
| **Enter** or **Ctrl+C** | Copy the annotated capture and close |
| **P** | Pin the capture as an always-on-top floating window and close |
| **Ctrl+S** | Save the capture to a file (PNG, JPEG, WebP, BMP or PDF) |
| **Ctrl+E** | Continue in the full editor |
| **I** | Toggle the eyedropper to pick a color from the capture |
| **Esc** | Cancel the capture |
| **Ctrl+Z** | Undo |
| **Ctrl+Y** or **Ctrl+Shift+Z** | Redo |

When a text is being typed or an annotation is selected, **Enter** and **Esc** apply to it first.

## Pinned window

| Shortcut | Action |
|---|---|
| Drag | Move the pinned capture across any monitor |
| Mouse wheel | Zoom in or out (`25%–400%`), anchored at the pointer |
| **Ctrl**+mouse wheel | Adjust window opacity (`20%–100%`) |
| **0** or **1** | Reset zoom to actual size (`100%`) |
| **Ctrl+C** | Copy the pinned image to the clipboard |
| Right-click | Open the context menu (Copy, Zoom, Opacity, Close) |
| Double-click, middle-click or **Esc** | Close the pinned window |

## Editor

### Editing

| Shortcut | Action |
|---|---|
| **Ctrl+S** | Save the capture as PNG, JPEG, WebP, BMP or PDF |
| **Ctrl+V** | Paste an image from the clipboard as an editable layer |
| **Ctrl+Z** | Undo |
| **Ctrl+Y** or **Ctrl+Shift+Z** | Redo |
| **Ctrl+A** | Select all annotations |
| **Ctrl+Click** or **Shift+Click** | Add or remove an annotation from the selection |
| Drag on empty canvas (in **Select**) | Marquee-select multiple annotations |
| **Delete** or **Backspace** | Delete the selected annotation(s) |
| **Ctrl+D** | Duplicate the selected annotation(s) |
| **]** / **[** | Bring forward / send backward one layer |
| **Shift+]** / **Shift+[** | Bring to front / send to back |
| **Shift** + drag rotation handle | Snap rotation to 45° increments |
| **I** | Toggle the eyedropper to pick any pixel's color |
| Arrow keys | Move the selected annotation(s) 1 pixel |
| **Shift**+arrow keys | Move the selected annotation(s) 10 pixels |
| Double-click a text or callout | Edit its text |
| **Esc** | Clear the selection or cancel the eyedropper |

### Typing text

| Shortcut | Action |
|---|---|
| **Enter** | Confirm the text |
| **Shift+Enter** | Start a new line |
| **Esc** | Cancel the text |

### Zoom and view

| Shortcut | Action |
|---|---|
| **Ctrl**+mouse wheel | Zoom in or out at the pointer |
| **Ctrl+Plus** | Zoom in |
| **Ctrl+Minus** | Zoom out |
| **Ctrl+0** | Fit the whole image in the window |
| **Ctrl+1** | Show the image at actual size |
| Mouse wheel or middle button drag | Pan a zoomed image |

## Library

| Shortcut | Action |
|---|---|
| **Ctrl+Click** | Toggle a capture in the multi-selection |
| **Shift+Click** | Select a range of captures |
| Drag to another app | Drop the selected file(s) directly into Explorer, browsers or chat apps |
| **Delete** (with the pointer over the library) | Move the selected capture(s) to the Recycle Bin |

## Recording and step-by-step capture

Recording and step-by-step capture are controlled with the buttons in their panels (**Esc** cancels before starting). During a step-by-step capture, each **Enter** you press in any app becomes a step.

## Scrolling capture

| Shortcut | Action |
|---|---|
| **Esc** | Stop the automatic scrolling capture and keep what was captured |
