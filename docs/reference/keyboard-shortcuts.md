# Keyboard shortcuts

## Global

These work from any app while SnapKit is running, including when it's hidden in the tray.

| Shortcut | Action |
|---|---|
| **Alt+Shift+S** | Start a region capture. You can change it in [Preferences](preferences.md#global-capture-shortcut). |

## Selecting an area

| Shortcut | Action |
|---|---|
| Drag | Select a region |
| Click | Capture the window under the pointer |
| **Enter** or **Ctrl+C** | Confirm an adjusted region |
| Double-click inside the region | Confirm an adjusted region |
| **Esc** | Cancel the capture |

## Quick annotation

| Shortcut | Action |
|---|---|
| **Enter** or **Ctrl+C** | Copy the annotated capture and close |
| **Ctrl+S** | Save the capture to a file |
| **Ctrl+E** | Continue in the full editor |
| **Esc** | Cancel the capture |
| **Ctrl+Z** | Undo |
| **Ctrl+Y** or **Ctrl+Shift+Z** | Redo |

When a text is being typed or an annotation is selected, **Enter** and **Esc** apply to it first.

## Editor

### Editing

| Shortcut | Action |
|---|---|
| **Ctrl+Z** | Undo |
| **Ctrl+Y** or **Ctrl+Shift+Z** | Redo |
| **Delete** or **Backspace** | Delete the selected annotation |
| **Ctrl+D** | Duplicate the selected annotation |
| Arrow keys | Move the selected annotation 1 pixel |
| **Shift**+arrow keys | Move the selected annotation 10 pixels |
| Double-click a text or callout | Edit its text |

### Typing text

| Shortcut | Action |
|---|---|
| **Enter** | Confirm the text |
| **Shift+Enter** | Start a new line |
| **Esc** | Cancel the text |

### Zoom and view

| Shortcut | Action |
|---|---|
| **Ctrl**+mouse wheel | Zoom in or out at the pointer |
| **Ctrl+Plus** | Zoom in |
| **Ctrl+Minus** | Zoom out |
| **Ctrl+0** | Fit the whole image in the window |
| **Ctrl+1** | Show the image at actual size |
| Mouse wheel or middle button drag | Pan a zoomed image |

## Library

| Shortcut | Action |
|---|---|
| **Delete** (with the pointer over the library) | Move the selected capture to the Recycle Bin |

## Recording and step-by-step capture

Recording and step-by-step capture are controlled with the buttons in their panels. During a step-by-step capture, each **Enter** you press in any app becomes a step.

## Scrolling capture

| Shortcut | Action |
|---|---|
| **Esc** | Stop the automatic scrolling capture and keep what was captured |
